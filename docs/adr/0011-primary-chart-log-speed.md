# ADR-0011: 主グラフを対数速度軸とし、0 cpm は軸を分けて描く

- 状態: 採択（Phase 3）
- 置き換え: [ADR-0009](0009-primary-chart-linear-cpm.md)（線形 cpm を主グラフとする決定）
- 関連: SPEC §1.1、SPEC §8.3、ADR-0001、ADR-0002、ADR-0006

## 文脈

ADR-0009 は主グラフを線形 cpm 軸と定めた。根拠は「対数軸では 0 cpm を描けない」であり、これ自体は正しい。

しかし Phase 3 の画面確認で、前提の取り違えが判明した。

**一次資料の速度軸は対数である。** ADR-0009 の本文は原典の対数軸を「読破時間の対数軸」と記していたが、実際には:

- **図3**（手描き用グラフ用紙, p.7）: 左縦軸 = 読むのに要した時間（秒、対数 1.0〜120）、右縦軸 = 読書速度（cpm、対数 1800〜15）
- **図4**（測定例のプロット, p.9）: 縦軸 = **読書速度（文字／分）、対数目盛**（1／10／100／1000）

すなわち原典は速度そのものを対数で描いている。ミネソタ大学の原著論文および MNREAD アプリも対数読書速度を縦軸に取っており、曲線フィット（two-limb、negative exponential）もいずれも $\log_{10} v$ の空間で定義される。

線形軸を主表示にすると、**検者が見慣れた形とも、文献の図とも、フィットが行われる空間とも異なる**曲線を、目視判定（臨床の主値, ADR-0006）の材料として提示することになる。ADR-0009 はこの費用を過小評価していた。

## 決定

主グラフの軸を **横軸 = 距離補正後 logMAR、縦軸 = 読書速度 cpm（常用対数目盛）** とする。**目盛は対数のみとし、線形表示は用意しない。**

**0 cpm の点は捨てない。** 対数領域の下に軸を分断した専用の帯を設け、そこに描く。帯は対数領域と視覚的に切り離し、`0` と明示する。

### 算出と作図で正本の扱いを分ける

**算出は日本語版の一次資料にのみ従う。** 英語版の定数（10語、40cm、200 wpm の ACC 除数）を日本語モードに持ち込まないという ADR-0001 は変わらない。

**一方、作図の設計は日英いずれの文献も参照してよい。** SPEC §1.1 が米国公式を「概念の参照のみ」と位置づけているのがまさにこの区別であり、軸の取り方は値を生まないため、日本語版の値の正しさに影響しない。本 ADR で米国側の作図慣行を根拠に挙げているのは、この線引きの内側での参照である。

判定基準は「その参照が**数値を変えるか**」である。変えるなら日本語版一次資料のみ、変えないなら双方を参考にしてよい。

## 根拠

対数軸が 0 を表現できないという ADR-0009 の指摘は有効であり、**それは軸を捨てる理由ではなく、0 を別に描く理由である。**

原典自身がこの欠落を起こしている。マニュアル §4 の測定例は 0.5 logMAR で1文字も読めておらず（0 cpm）、この点が読書視力 0.8 logMAR を決めた境界そのものであるが、図4 のプロットは 0.6 logMAR で途切れ、0.5 logMAR の点が描かれていない。軸を分ければ、原典の作図法に従いながらこの欠落だけを埋められる。

標準の形を採ることの利益は、目視判定の質に直結する:

- 検者は図3 のグラフ用紙で手描きしてきた形を見慣れている
- 日本語版・英語版いずれの文献の図とも、他施設の記録とも直接見比べられる
- フィットが行われる空間と表示空間が一致し、フィット曲線を歪みなく重ねられる（ADR-0009 が「影響」に挙げた逆変換の不整合が消える）

**線形表示を選択肢としても残さない。** 目視判定を主値とする以上、検者ごと・回ごとに異なる形の曲線を見て判定できてしまう状態は、再現性（本プロジェクトの第一目的）を損なう。表示の選択肢は、判定材料が1つに定まらないという費用を伴う。

## 影響

- 0 cpm 点は対数領域ではなく分断帯に描く。**対数回帰から除外するという規則（SPEC §5.5.3）は従来どおり**であり、表示と回帰で扱いが異なる点は変わらない。
- 0 cpm 点を通る折れ線は引かない（対数領域と帯をまたぐ線は傾きに意味を持たない）。帯の点は独立した印として描く。
- 正速度が 1 cpm を下回る場合に備え、対数目盛の下端は実測値に応じて桁を延ばす。目盛の外へ点を丸め込まない。
- 算出結果は一切変わらないため `algorithmVersion` は据え置き、`specVersion` のみ上げる。

## ADR-0009 との関係

ADR-0009 の事実認定（対数軸は 0 cpm を描けない／原典の図4 が 0.5 logMAR を落としている／図3 の右軸は誤り0を仮定した近似である）はいずれも維持する。覆すのは「したがって主グラフを線形にする」という結論のみである。
