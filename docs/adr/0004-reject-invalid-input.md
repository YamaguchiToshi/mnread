# ADR-0004: 不正入力は拒否する（暗黙の丸め・補完をしない）

- 状態: 採択（Phase 0）
- 関連: SPEC §6、ADR-0002

## 文脈

試作は誤り数が $n_0$ を超えた場合に速度を黙って0に丸めていた。

```js
return { ..., cpm: Math.max(0, cpm) };
```

また $t \le 0$ の行は `empty` として静かに脱落し、$N$ と $E$ から外れていた。いずれも画面上は正常な結果に見える。

## 決定

以下は入力エラーとして拒否し、解析結果を返さない。

- $t_i \le 0$ または非有限
- $e_i < 0$、$e_i > n_0$、または非整数
- $D \le 0$ または非有限
- 同一 logMAR の重複行（反復試行の明示がない場合）
- 状態と `time`/`errors` の有無の矛盾

error が1件でもある場合、**部分的な結果を返さない**。検証結果のみを返す。

解析関数は例外を投げるのではなく、判別可能な返り値を用いる。

```ts
type AnalysisOutcome =
  | { ok: true;  result: AnalysisResult }
  | { ok: false; issues: readonly ValidationIssue[] }
```

## 根拠

臨床データの入力誤りは、拒否されれば入力し直せるが、丸められると誤った値のまま電子カルテに転記される。「30文字中32文字の誤り」は測定または転記の誤りであって、0 cpm という測定事実ではない。

例外ではなく返り値にするのは、UI が全エラーを行単位で同時表示する必要があるため（最初の1件で中断させない）。

## 影響

- 入力UIは行ごとにエラーを即時表示し、赤字で拒否する（Phase 3）。
- 部分入力中は「未入力」状態であってエラーではない。両者を区別する。
