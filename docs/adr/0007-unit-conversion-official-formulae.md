# ADR-0007: 単位換算に公式式を用いる（pt・M値）

- 状態: 採択（Phase 0）。**M値の定数は一次資料で確認済み（2026-07-31、OPEN-1 解決）**
- 関連: SPEC §5.7

## 文脈

試作の換算には2つの問題があった。

**ポイント換算** — `1M ≈ 10pt` というヒューリスティックを使い、コード内で「臨床式ではない」と注記していた。公式 Q&A には正式な換算式が存在する。

**M値** — `M = 10^L` を用いていた。公式 Q&A の式は $M = 10^{L-0.4}$ である。

数値の差は大きい。

| logMAR | 試作 M | 報告書 M | 試作 pt | 公式式 pt |
|---|---|---|---|---|
| 1.0 | 10.00M | 3.98M | 100pt | 27.75pt |
| 0.6 | 3.98M | 1.59M | 39.8pt | 11.05pt |

M値は電子カルテ文の「新聞(1M)に対し約N倍拡大」に直接使われるため、試作は**必要倍率を約2.5倍過大に伝えていた**。

## 決定

公式式を用いる。

$$pt_{30}(L) = 1908\tan\!\left(10^{L}\cdot\frac{5}{60}\cdot\frac{\pi}{180}\right), \qquad pt_D(L) = pt_{30}(L)\cdot\frac{D}{30}$$

$$M = 10^{\,L - 0.4}, \qquad VA = 10^{-L}$$

換算にはすべて**距離補正後の logMAR** を用いる。ポイント値は「MNREAD-J相当」と明記し、特定フォントの字面高と同一視しない。

M値の定数 0.4 は `M_REFERENCE_LOG_OFFSET` として1箇所に定義する。

## 根拠

支援現場に渡す推奨文字サイズと推奨倍率は、そのまま拡大読書器やルーペの選定に使われる。ヒューリスティックで2〜3倍ずれた値を出すことは、過剰な機器導入または不十分な支援に直結する。

## 一次資料による確認（OPEN-1 の解決）

当初、定数 0.4 は 40cm 基準（$\log_{10}(1/0.4) = 0.398$）に対応するため、標準距離 30cm の MNREAD-J では $10^{L-0.523}$ ではないかという疑義があった。`oda.lab/` の原典により **0.4 が正しい**ことが確認された。

- **Q&A A7** が式を明記: 「M値 = 10^(臨界文字サイズのlogMAR − 0.4)」。あわせて「1.0 logMAR であると推定された人の場合、その文字サイズのM値は 4.0」とする（$10^{0.6} = 3.98$）。
- **マニュアル §4.3**: 「1.1 logMAR は、チャートに印刷されているように 5M」（$10^{0.7} = 5.01$）。
- **マニュアル §1.2**: 「4M サイズの文字では…このときの印刷文字はほぼ 28 ポイント」（$pt(1.0) = 27.75$）。M と pt の2式が独立に整合する。
- **図1a のチャート印刷 M 系列**（8.0 / 6.3 / 5.0 / 4.0 / 3.2 …）は R10 系列であり、本式と全件1%以内で一致。

M は Magnification の頭字で、新聞を読むのに必要な倍率を表す（Q&A A7）。30cm 基準の解釈が誤りだったのは、M が「印刷物の物理サイズ」ではなく「新聞に対する倍率」として定義されているためである。

ポイント換算式も **Q&A A4.3 の公式表21件（9桁）と最大相対誤差 2.8×10⁻⁹** で一致することを確認した。

## 影響

- 患者向けレポートの推奨 pt と推奨倍率がすべて変わる。試作は必要倍率を約2.5倍過大に伝えていた。
- CPS 相当 pt と支援余裕（+0.1 logMAR ≒ 1.26倍）は分けて表示する。
- 上記の原典表はすべて `packages/fixtures` にゴールデンデータとして取り込む。
