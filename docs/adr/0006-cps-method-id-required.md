# ADR-0006: CPS には算出法IDを必ず伴わせ、主値は目視判定とする

- 状態: 採択（Phase 0）
- 関連: SPEC §5.5

## 文脈

試作は「MRS の85%を初めて下回る直前の行」という単一の自動判定のみを実装し、値を `CPS: 0.60 logMAR` として出力していた。この85%という閾値は公式資料に根拠がなく、また値だけを見ても由来が分からない。

CPS は算出法によって系統的にずれる。Cheung らの報告では、80%閾値の CPS は two-limb CPS より平均 0.07 logMAR 大きく、90%では 0.15 logMAR 大きい。Baskaran らの101曲線研究では、7名の評定者間 ICC が MRS で約0.97、**CPS では約0.77** であり、0.2 logMAR 程度の評定者差が珍しくない。

## 決定

1. **CPS値を算出法IDなしで出力しない。** 画面・EMRテキスト・書き出しファイルのいずれにも「CPS = 0.6 logMAR」単独の行を出さない。
2. 臨床の主値は `manual_visual_2002`（検者がグラフ上で選択したプラトー）とする。
3. `sdev_1.96`、`expdecay_80/90/95` は参考値として併記し、主値を置換しない。
4. 検者が自動値を採用・上書きした場合、操作と理由を記録する。
5. 算出法間で 0.2 logMAR を超えて乖離したら目視レビューを要求する。

## 根拠

CPS の評定者間一致は本質的に不完全であり、単一の「正解」は存在しない。この不確かさを平均や閾値で押し潰すと、値の信頼できなさが見えなくなる。公式マニュアル自身も、MNJA の自動算出がばらつきの大きいデータで CPS を過小推定しうるとして、目視値の採用または再測定を指示している。

主値を目視に置くのは、臨床・教育現場の既存実践との互換性を保つため。自動値は「検者の判断を助ける参考情報」であって、判断の代替ではない。

## 影響

- グラフ上でのプラトー点選択と CPS/MRS のドラッグ調整は**必須機能**であり、エッジケースではない（Phase 4）。
- 除外した外れ値は、点を削除するのではなく除外として記録する。
- `expdecay_*` は Phase 2 の実装対象だが、臨床運用開始の必須条件ではない。
