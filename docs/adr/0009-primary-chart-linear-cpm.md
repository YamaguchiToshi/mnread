# ADR-0009: 主グラフを線形 cpm 軸とする

- 状態: **置き換え済み（Phase 3）** — [ADR-0011](0011-primary-chart-log-speed.md) を参照
- 関連: SPEC §8.3

> **置き換えの要点**: 本 ADR の事実認定（対数軸は 0 cpm を描けない／原典の図4 が 0.5 logMAR の 0 cpm を落としている／図3 の右軸は誤り0を仮定した近似である）は維持する。覆したのは結論のみで、0 cpm は「軸を捨てる理由」ではなく「軸を分けて描く理由」であった。また下記「文脈」の記述には誤りがあり、原典の図4 は**読書速度そのものを対数目盛**で描いている。

## 文脈

基本仕様書および試作は、公式マニュアル図3に倣って「左縦軸 = 読破時間（対数）、右縦軸 = 読書速度（対数）」の両対数風プロットを主グラフとしていた。

## 決定

主グラフの軸を **横軸 = 距離補正後 logMAR、縦軸 = 読書速度 cpm（線形軸）** に変更する。

読書時間の対数軸表示は、公式マニュアル図3との対照用に**副表示として残す**。

## 根拠

対数軸では 0 cpm を表現できない。全文字を読み損じた読み材料（$e = n_0$）は 0 cpm という測定された事実であり、ロービジョン例では読書視力限界の直上に位置する最も重要な点の1つである。対数軸ではこの点が描画できず、曲線の小文字側が欠落する。

**この欠落は原典自身に現れている。** マニュアル §4 の測定例では 0.5 logMAR で1文字も読めておらず（0 cpm）、この点は読書視力を決める境界そのものである。しかし図4のプロットは対数縦軸のため 0.6 logMAR で途切れており、0.5 logMAR の点が描かれていない。

さらにマニュアル §3.2 は、図3のグラフ用紙の速度目盛について「読み誤りがゼロであるということを仮定した場合の読書速度ですから、少し正確でない場合があります」と自ら断っている。原典の作図法は近似であり、誤り補正済みの実速度を線形軸に描く方が事実に忠実である。

検者がプラトーを目視判定する（ADR-0006）以上、判定の材料となる曲線が事実を欠いていてはならない。

線形軸はプラトーの平坦さと低下の始まりを視覚的に評価しやすく、CPS の定義（速度低下が始まる直前のサイズ）に直接対応する。

## 影響

- 曲線フィット（対数空間で行う）と表示（線形空間）で軸が異なる。フィット結果を描画する際は逆変換が必要。
- 0 cpm 点は曲線上に描画するが、対数回帰からは除外し除外件数を表示する（SPEC §5.5.3）。
- 公式マニュアルの図と並べて見る利用者のために、副表示への切り替えを1操作で行えるようにする。
