# ADR-0002: 項目の状態を6値の列挙で表す

- 状態: 採択（Phase 0）
- 関連: SPEC §4.2、ADR-0004

## 文脈

試作は行の状態を `{ time, errors, unread }` の組み合わせで表現していた。この表現では以下が区別できない。

- 「試行したが全く読めなかった」（0 cpm、$N$に算入）と「検査を終了して提示していない」（欠測、$N$に算入しない）
- 「読んだが時間が未記録」（速度は欠測だが $E$ には寄与）と「未提示」
- 「上位を省略した（読めるとみなした）」と「大文字側が読めない（輪状暗点）」

試作では時間が未入力の行はすべて `empty` に落ち、$N$ と $E$ から静かに脱落していた。

## 決定

項目の状態を排他的な6値の列挙とする。

| 状態 | $N$ | $E$ | 速度 | 曲線 |
|---|:-:|---|---|---|
| `read` | ○ | $e_i$ | $60(n_0-e_i)/t_i$ | ○ |
| `attempted_unread` | ○ | $n_0$ | 0 cpm | ○ |
| `presented_time_missing` | ○ | $e_i$ | 欠測 | × |
| `unpresented_after_stop` | × | — | 欠測 | × |
| `skipped_large_assumed_readable` | ○ | 0 | 欠測 | × |
| `skipped_large_unreadable` | ○ | $n_0$ | 0 cpm | ○＋フラグ |

真偽値の組み合わせで状態を再構成しない。状態と `time`/`errors` の有無が矛盾する入力は `ERR_STATE_FIELD_MISMATCH` で拒否する。

## 根拠

「0 cpm」と「欠測」は数学的に別物である。0 cpm は測定された事実（全文字を読み損じた）であり曲線上の点だが、欠測は情報がない状態で、対数変換もできなければ平均にも入れられない。この2つを混同すると、MRS が過小になり、フィットが破綻する。

なお RA については、$e = n_0$ の項目を算入してもしなくても値は変わらない（$-0.1 + 0.1n_0/n_0 = 0$、SPEC §5.3.3）。したがって状態の区別は **RA のためではなく、曲線・MRS・CPS のために必要**である。

## 影響

- 入力UIは6状態をキーボードから選べる必要がある（Phase 3）。
- `mnreadR` も同等の状態区別を持つため、英語モードの回帰テストで対応付けができる。
