# ADR-0013: 判読3ゾーンの境界を RA と CPS に置き、支援余裕は別枠に出す

- 状態: 採択（Phase 4）
- 関連: SPEC §5.7、SPEC §5.8、SPEC §8.2.2、OPEN-7、ADR-0006

## 文脈

A4 患者・支援者向けレポートは「快適／努力／不可」の3ゾーンで文字サイズを示す（PLAN Phase 4）。**原典にこの区分の規定はない。** 本プロジェクトが定める必要がある。

一方 SPEC §5.7 は、支援用の推奨サイズについて次を求めている。

$$pt_{\text{下限}} = pt(CPS), \qquad pt_{\text{上限}} = pt(CPS + r), \quad r = 0.1$$

> CPS は「快適さを保証する推奨サイズ」ではなく「最大速度を支える最小サイズ」であるため、この区別を表示上も崩さない。

素直に読むと「快適ゾーンの下端は $CPS + r$ ではないか」という案が出る。CPS ちょうどでは余裕がないのだから、というものである。

## 決定

**ゾーン境界は RA と CPS の2点のみに置く。**

| ゾーン | 範囲 |
|---|---|
| 不可 | $L^c < RA$ |
| 努力 | $RA \le L^c < CPS$ |
| 快適 | $CPS \le L^c$ |

**支援余裕 $r = 0.1$ logMAR はゾーンの境界にしない。** 推奨サイズ範囲 $[pt(CPS),\ pt(CPS+r)]$ として、ゾーン図とは**別枠**に置く。

## 根拠

**$CPS \le L^c < CPS + r$ の帯では、実際に最大読書速度が出ている。** これを「努力」と表示すると、測定した事実と患者に見せる図が食い違う。ゾーン図が答えるべき問いは「このサイズはどう読めるか」であり、そこに推奨の安全率を混ぜてはならない。

**SPEC §5.7 の要求は、余裕を境界に織り込むことではなく、余裕と CPS を分けて見せることである。** 余裕をゾーン境界に溶かし込む案は、まさに §5.7 が禁じた「2つを混ぜて1つの推奨値として提示する」形になる。別枠に出すほうが原文に忠実である。

**4区分（不可／努力／最大速度／推奨）は事実として最も正確だが、採らない。** 患者・支援者に渡す1枚物で、隣接する2帯の違い（どちらも最大速度が出る）を読み分けさせるのは負担が大きい。3ゾーン＋別枠の推奨範囲であれば、「読める／速く読める」の軸と「どのサイズを用意するか」の軸が分離したまま、帯は3つで済む。

## 帰結

- ゾーンは CPS に依存する。**CPS が推定不能ならゾーンを出力しない**（`null`）。数値を出せないことを数値で表現しない（SPEC §5.5.4 と同じ規則）
- 誤りが多い症例では $RA > CPS$ となりうる（RA の誤り項 $+E/d$ が RA を押し上げるため）。このとき「努力」ゾーンは空になる。**値を入れ替えず**、空のまま返して `RA_ABOVE_CPS` を立てる
- ゾーン境界には CPS の算出法 ID を必ず添える（ADR-0006）。レポートは患者の手に残る紙であり、どの方法で出した値かが読めなければならない
- **OPEN-7 として Phase 5 の較正対象**に残す。とくに「努力」の下端を RA そのものに置いてよいかは、RA 近傍が実際には数文字を拾える程度でしかない例があるため、ORT の体感と突き合わせる
- ゾーンは患者・支援者向けの目安表示に限る。**EMR テキストと生データ書き出しには持ち込まない**（そちらは測定値と算出法で完結させる）
