# ADR-0008: 日本語版で ACC を正規化しない

- 状態: 採択（Phase 0）
- 関連: SPEC §5.6

## 文脈

英語版 MNREAD の ACC（Reading Accessibility Index）は、1.3〜0.4 logMAR の10段の平均読書速度を 200 wpm で割った指標である。分母 200 は 18〜39歳の正常視・英語話者365名の平均 200.70 wpm に基づく。

`mnreadR` に実装があるため、日本語データに対しても機械的に計算できてしまう。

## 決定

日本語版では 1.3〜0.4 logMAR の平均 cpm を**非正規化のまま**出力する。

- 表示名は「読書アクセシビリティ対象範囲平均速度」とし、**`ACC` と単独表示しない**。
- `acc_normalized` は常に `null` を返す。
- 欠測の扱いは原著規則に従う（読書視力限界により読めない→0、大文字が読めない→0、便宜上省略→次の実測速度で補完）。それ以外の補間を行わない。

## 根拠

文字/分と語/分は単位が違うだけでなく、言語構造、単語長、漢字かな構成、分かち書きの有無が異なる。英語話者の正規化定数を cpm に適用した値は、見た目は 1.0 前後の解釈しやすい数字になるが、何も意味しない。

さらに MNREAD-J と Jk でも速度水準が異なるため、正規化定数は少なくともチャート種別ごとに検証が必要になる。日本語版の正常視基準値は現時点で確立していない。

## 影響

- 将来 $K_J$ / $K_{Jk}$ が確立した場合に限り、`acc_normalized` を追加する。その際も英語版 ACC と同名で扱わない。
- 標準外距離での測定では `acc_nominal` と測定距離を併記し、補間による「30cm標準化 ACC」を原著 ACC として扱わない。
