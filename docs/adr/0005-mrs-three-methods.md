# ADR-0005: MRS は3方式を並列出力する

- 状態: 採択（Phase 0）
- 関連: SPEC §5.4

## 文脈

公式マニュアルの MRS 定義には内部矛盾がある。

- 定義本文: CPS 以上の各文字サイズの**読書速度の平均**
- 計算例: 3試行の**読書時間を平均**してから cpm に換算

数値は一致しない。公式例の 4.45 / 4.12 / 4.56 秒では、速度の算術平均が 412.0414760 cpm、平均時間からの換算が 411.2718964 cpm となる。差は小さいが、時間のばらつきや誤り数が大きいと拡大する。

試作は第3の方式（最大 cpm の90%以上の行の平均）を採っており、いずれの公式定義とも異なる。

## 決定

3値を並列に出力し、実装が黙って一方を選ばない。

| 出力 | 定義 | 扱い |
|---|---|---|
| `mrs_arithmetic` | プラトー内 $v_i$ の算術平均 | **標準値** |
| `mrs_pooled` | 総正読文字数 / 総時間 | 補助値 |
| `mrs_legacy_mean_time` | 平均時間から換算 | 公式例互換。$P$ 内全項目が $e_i=0$ のときのみ有効、他は `null` |

付随して `mrs_sd_cpm` と `mrs_n` を返す。標準値と旧方式が既定5%を超えて乖離したら `MRS_METHOD_DISAGREEMENT` を立てる。

## 根拠

標準値を定義本文側に置くのは、計算例の手続きが「全項目で正読文字数が等しい」場合にしか一般化できないため。誤りを含む項目が混ざると、平均時間からの換算は意味を持たない。

一方、既存の MNJA や過去の紙記録と突き合わせる場面では計算例互換値が必要になる。どちらか一方を捨てると、過去データとの連続性か定義への忠実性のどちらかを失う。

`mrs_legacy_mean_time` を条件付きで `null` にするのは、有効でない条件下で数値を出すと比較に使われてしまうため。

## 影響

- プラトー集合 $P$ は CPS と一体で決まる（試作のようにピーク速度から独立に決めない）。
- 電子カルテ用テキストには標準値のみを載せ、3値は詳細表示・書き出しファイルに含める。
