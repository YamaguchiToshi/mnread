# ADR-0001: 正本の階層を固定する

- 状態: 採択（Phase 0）
- 関連: SPEC §1.1

## 文脈

MNREAD には日本語版公式マニュアル、University of Minnesota の英語版公式資料、`mnreadR` 実装、複数の曲線推定論文が並存する。試作段階では基本仕様書と各種資料が同列に扱われており、値の由来を追えなかった。

英語版と日本語版は式が異なるため（項目長、誤り単位、標準距離、RA式）、どちらの資料を根拠にしたかで結果が変わる。

## 決定

正本を4段階に順位付ける。

1. 小田ら『MNREAD-J, Jk Manual』(2002-05-18) — 日本語版採点の規範
2. 小田研究室 MNREAD-J Q&A — 単位換算・採点細則
3. UMN 英語版公式 — 概念参照のみ
4. `mnreadR` / Cheung 2008 / Baskaran 2019 — 任意アルゴリズムの出典

式レベルのテストはすべて1または2の参照箇所に紐づける。

## 根拠

MNREAD-J/Jk は英語版の翻訳ではない。項目長（30/24文字 対 10語）、誤り単位（文字 対 語）、標準距離（30cm 対 40cm）、RA式のいずれもが異なる。英語版の定数を1つでも持ち込むと、臨床値が静かにずれる。

## 影響

- 英語版の定数（10語、40cm、200 wpm）を日本語モードのコードに書かない。
- `mnreadR` は依存ライブラリではなく**固定版の検証オラクル**として扱う（2025-10-01 に CRAN からアーカイブ済みのため、2.1.7 をソース参照する）。
- 出典を特定できない式を実装しない。
