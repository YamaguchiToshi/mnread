# ADR-0016: プラトー帯は区間の最速1点を除いて推定し、プラトーは再推定の不動点とする

- 状態: 採択（Phase 5、2026-08-01）
- 関連: SPEC §5.5.2、§11 OPEN-3 / OPEN-8、ADR-0014、`docs/mnreadr-comparison.md` E-1

## 文脈

`mnreadR` との照合（ADR-0014）が見つけた本仕様側の実在の欠陥（E-1 / OPEN-8）。

`plateau_sdev_v1` の核は「平均が最大の隣接2点」である。したがって**単一の高い外れ値が
あれば、必ずそれを含む組が核になる**。核は2点しかないので、その標本 sd は外れ値の逸脱量
だけで決まる。

```
1.3:380  1.2:380  1.1:380  1.0:722  0.9:380  0.8:380  0.7:380  0.6:380
0.5:190  0.4:95   0.3:48   …                   ↑ 外れ値
核 = {1.0, 0.9}  水準 551.0  sd 241.8  帯の下限 77.0 cpm
→ プラトー 1.3〜0.4、CPS = 0.4（真値 0.6）
```

再推定は区間全体から帯を求め直すが、**広がった区間には外れ値が入ったままなので sd は
さらに大きくなり、引き戻されない。** 合成 `single_high_outlier` 族で 40/40 発生していた。

原典 §3.2 は CPS を「読書速度が落ちはじめる直前の文字サイズ」と定めており、
この曲線の CPS は 0.6 である。**0.4 は原典の定義に反する。** 臨床的には CPS の過小評価、
すなわち患者が最大速度で読めるサイズより小さい文字を推奨する方向であり、危険な向きである。

## 決定

### 1. 帯の標本から、最速の1点を除く（区間が4点以上のとき）

水準 $\mu$ とばらつき $s$ を、区間の速度から最速1点を除いた標本 $S$ から求める。

### 2. プラトーは再推定の不動点とする。達しなければ推定不能

区間が変化しなくなった時点の区間を採る。巡回した場合、または上限10回で収まらない場合は
**値を出さない**。

## 根拠

**1 について。** 単一の高い外れ値は、水準と標本 sd の**両方**を押し上げる。帯は
「水準からどれだけ下まで同じプラトーとみなすか」を決めるものなので、外れ値ひとつで
帯が二重に広がる。落とすのは最速側だけである — 遅い点はプラトーのばらつきが実際に
大きいことの証拠であり、落とすと帯が過小になる（`single_low_outlier` 族は修正前から
40/40 で、直す必要がない）。

しきい値が 4 なのは、3点の区間から1点落とすと残り2点になり、その標本 sd が弱く、
下限（5%）が常に効いてしまうため。**マニュアル §4 の測定例のプラトーはちょうど3点であり、
そこでは sd 22.07 が下限 20.60 を上回って効いている。下限 5% の根拠になっている当の計算を、
除外で骨抜きにしない。**

帯の水準は MRS ではない。MRS はプラトー内の全点の平均であり（SPEC §5.4）、除外は帯の
推定にしか及ばない。テストで固定してある。

**2 について。** 除外を入れると再推定が巡回しうる。広い区間では外れ値が除かれて帯が
締まり、核まで縮む → 核は2点なので除外が効かず帯が緩む → また広がる、という循環である。
合成600本のうち1本（`flat_no_decline`、低下がまったくない曲線）で実際に起きた。

**「10回目にたまたま居た区間」を返すのは、反復回数を定義に混ぜることである。**
±0.1 logMAR の精度指標では、この振動は「正解」として数えられていた（隣の段に居たため）。
指標が設計の破綻を隠したので、収束性を独立に測り、定義そのものを不動点に改めた。

## 検討して採らなかった案

| 案 | 合成600本の完全一致 | 却下の理由 |
|---|---|---|
| 核を隣接3点にする | 526 | `truncated_large_limb` が 40 → 26。プラトーが観測できない曲線に3点を強いる |
| 核を「遅いほうが最速の隣接2点」に | 515 | 単体ケース「核から広げた区間が上位2点だけの短い区間に負けない」が落ちる |
| 帯を中央値 + MAD に | 521 | 原典測定例で MAD 14.5 < 下限 20.6 となり、下限が常に効く（SD項が不活性化する） |
| 帯を下振れのみで推定 | 508 | 同上（片側 13.4 < 20.6）。精度も劣る |
| 自己整合な区間の宣言的列挙 | **115** | 長いプラトーを構造的に棄却する。CLAUDE.md が記録する「捨てた設計1」そのもので、実測で再現した |
| 最速点を散らばりからだけ除く（水準は全点） | 459 | 水準が外れ値で押し上がったままなので、帯が区間自身の点を排除する。40本で振動 |

採用案は 457 → **498**（±0.1 では 483 → 527）。

## 影響

- `single_high_outlier` 40/40 が真値と完全一致するようになった。他14族に退行はない
  （完全一致で下がったのは `gradual_transition` の 20 → 18 のみ。±0.1 では同数）。
- `mnreadR` オラクルとの一致は 408（68%）→ **451（75%）**、0.1 logMAR 超の相違は
  93 → 50 に減った。**収束させにいった結果ではない**（ADR-0014）— 原典の定義に近づけた
  副産物である。
- 推定不能が1本増えた（帯が収束しない曲線）。値を出さない側の失敗であり、
  `requiresReview` も立つ。
- 変異11件すべてがテストで検出される（除外なし / 落とす側を最遅に / しきい値 4→2 /
  不動点の要求なし / 除外を散らばりだけに、の新規5件を含む）。
- `algorithmVersion` 0.4.0 → 0.5.0、`SPEC_VERSION` 0.5.0 → 0.6.0。
