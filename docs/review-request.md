# 監修・実測検証のお願い（Phase 5）

MNREAD-J / MNREAD-Jk の記録用紙から、読書視力（RA）・最大読書速度（MRS）・臨界文字サイズ（CPS）を
算出するブラウザツールを試作しました。**計算の正しさは一次資料と突き合わせて確認済みですが、
臨床上の妥当性はまだ誰にも確認してもらっていません。** ここから先は開発側だけでは決められないため、
視能訓練士・眼科医の方に触っていただき、下記の点を見ていただきたく思います。

## 1. まず知っておいていただきたいこと

**このツールはまだ検証前です。** 出てくる値を診療にそのまま使わないでください。画面・電子カルテ用
テキスト・A4レポートのすべてに仕様版とアルゴリズム版、および「実測による検証は継続中」である旨を
表示しています。

**患者データは端末にもサーバにも残りません。** 入力した値はブラウザのメモリ上にあるだけで、
再読み込みすると消えます。外部への通信は行いません（ページ自体が外部通信を禁止する設定で配信されています）。
氏名欄は設けておらず、ID 欄だけがあります。

**書き出したファイルの扱いは院内規程に従ってください。** 「出力」画面から JSON / CSV を保存できますが、
これは検者が明示的に操作したときだけ生成されます。**実測値を含むファイルを、開発リポジトリや
メール・チャットにそのまま貼らないでください。** 検証結果を返していただく際は、後述のとおり
値のずれだけをお知らせいただければ十分です。

## 2. 触り方

画面は3面です。上部のタブで切り替わります。

| 画面 | 何をするところ |
|---|---|
| **入力** | 検査条件（チャート種別・視距離・眼・提示順など）と、19行ぶんの読み時間・誤り数 |
| **判定** | 曲線を見て、プラトー（速度が頭打ちになっている範囲）を確定する |
| **出力** | 電子カルテ用テキスト、A4レポート（印刷用）、生データの書き出し |

### 入力画面

検査をしながら打てるよう、**テンキーだけで最後まで進む**ようにしてあります。

| キー | はたらき |
|---|---|
| `0`–`9` `.` | 数値を入力 |
| `Enter` | 確定して次の行の時間へ |
| `+` | 同じ行の誤り数欄へ |
| `−` | 1つ前の欄へ戻る |
| `*` | この行を「不読（0 cpm）」にする |
| `/` | 状態メニューを開く（読めなかった理由の区別） |
| `↑` `↓` | 上下の行の同じ欄へ |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 取り消し / やり直し |

誤り数の既定は 0 なので、通常は **時間を打って `Enter`** の繰り返しで進みます。
入力しながら右側の曲線が伸びていくので、検査中に形が見えます。

### 判定画面

曲線上の点をクリックすると、その点がプラトーから外れます。CPS の境界線は左右に動かせます。
**CPS と MRS はどちらもプラトーの関数**（CPS = プラトー内の最小文字サイズ、MRS = プラトー内の平均速度）
なので、プラトーを動かすと両方が連動して変わります。自動推定値も併記していますが、
**主値はあくまで検者の目視判定**です。自動値をそのまま採用することもできます。

### 出力画面

電子カルテ用テキストはコピーできます。A4レポートは印刷プレビュー（`Ctrl+P` / `⌘P`）で
1枚に収まるようにしてあります。**施設名の欄は設けていません。** 上端を 20 mm 空けてあるので、
院のレターヘッド用紙に刷るか、院印を押してお使いください。

推奨サイズの見本を実寸で刷っているため、**印刷倍率は 100%（「用紙に合わせる」を外す）**で
出してください。紙面下部の 50 mm 目盛りで確かめられます。

### 試す材料がない場合

過去記録が手元になくても構いません。適当な値（たとえば大きい文字で 5 秒前後、小さくなるにつれて
遅くなり、最後の数行は読めない）を打つだけで、曲線・判定・出力の一巡は確認できます。

## 3. 見ていただきたい点

### (a) 判読3ゾーンの区分と文言 ★もっとも自信がない箇所

A4レポートで、文字サイズを3つの帯に分けて患者・支援者に示しています。境界は
**読書視力（RA）と臨界文字サイズ（CPS）** に置いていますが、**この区分は原典に規定がなく、
本プロジェクトの裁定です。**

とくに伺いたいのは次の点です。

- 「読めるが遅くなる」帯の**下端を RA そのものに置いてよいか**。RA 近傍は実際には数文字を拾える
  程度でしかない例があり、患者・支援者が「この大きさなら時間をかければ読める」と受け取ると
  実態と食い違うおそれがあります。
- 3つの帯の呼び名（**「読めない」「読めるが遅くなる」「最も速く読める」**）と説明文が、
  患者・支援者にそのまま渡せる言い方になっているか。

### (b) A4レポートの日本語

患者本人・家族・学校や職場の支援者に、そのまま手渡せる水準でしょうか。
専門用語の残り、言い回しのきつさ、逆に曖昧すぎる箇所などをご指摘ください。

### (c) 電子カルテ用テキストの項目立て

貼り付け先の運用に合っていますか。項目の順序、不要な行、逆に必ず要るのに無い項目
（他院の運用で必須になっているものなど）をお知らせください。

### (d) 推奨文字サイズの示し方と「実物大の見本」

下限（CPS 相当）と、ゆとりをもたせた値（CPS + 0.1 logMAR 相当）の**2値**で示しています。
支援の現場で使える形になっているでしょうか。1値のほうがよい／範囲より具体的な書体例が要る、
といったご意見も歓迎します。

あわせて、A4レポートには**推奨サイズの実物大の見本**（明朝体の「読」を、下限とゆとりの
2サイズで紙の上に実寸表示）と、**50 mm の校正目盛り**を刷っています。ねらいは
「35 ポイント」という数字だけでは患者・支援者に大きさが伝わらないことの補いです。

- 見本があることで話が早くなるか、逆に紙面が煩雑になっていないか
- **倍率 100% で印刷されているか**を目盛りで確かめる運用が、院内で現実的か
  （縮小印刷されると見本の大きさが狂います。目盛りはその検出用です）
- 見本の文字を「読」1字にしていますが、単語や文のほうがよいか

### (e) 過去記録との突き合わせ ★可能であれば

**過去の記録用紙 1〜数例**を入力し、手計算または既存の MNJA が出した値と比べてください。

- 式レベルの値（各行の読書速度、読書視力）は**完全に一致するはず**です。ずれたら不具合です。
- CPS は**目視判定と ±0.1 logMAR 以内**を目標にしています。
- ずれた例は、**原因が説明できるまで追いたい**と考えています。ずれた記録があれば、
  その旨を（値だけで結構です）お知らせください。

### (f) 二重入力（お二人以上に見ていただける場合）

**同じ記録用紙を2人が独立に入力し、結果が一致するか**を見ていただけると、入力画面の
取りこぼしをもっとも効率よく見つけられます。一致しなかった場合、どの行で食い違ったかを
お知らせください。

## 4. 返答していただきたい形

箇条書きのメモで結構です。次の観点で書いていただけると助かります。

1. **これは直さないと使えない** — 誤った値が出る、操作が破綻する、患者に渡せない文言
2. **直したほうがよい** — 使えるが手間が増える、言い方が気になる
3. **好みの範囲** — あってもなくてもよい

「触ったが特に問題なし」という返答も、それ自体が結果として意味があります。

**値のずれを報告される場合**は、患者が特定できる情報を含めず、次だけをお知らせください。

- チャート種別（J / Jk）、視距離、眼
- ずれた項目（RA / CPS / MRS のどれか）
- こちらの値と、手計算・MNJA の値
- 可能であれば、その行の読み時間と誤り数

## 5. 参考: 何がどこまで確認済みか

| 対象 | 状態 |
|---|---|
| ポイント換算、距離補正、小数視力、読書速度 | 公式マニュアルと Q&A の数表に対して数値照合済み |
| マニュアル §4 の測定例（19行1式） | RA・CPS・MRS・M値がいずれも原典の記載値を再現 |
| 自動テスト | 497 件（うち計算コア 344 件） |
| **実測記録との突き合わせ** | **未実施（本依頼）** |
| **患者・支援者向け文言の臨床的妥当性** | **未確認（本依頼）** |

最大読書速度は、公式マニュアルの本文と測定例で算出法が食い違うため、**3方式すべてを併記**しています
（測定例では 412 / 411 / 411 cpm に分かれ、マニュアル自身の記載値は 411）。
どれか1つに寄せると、原典が決めていないことを黙って決めることになるためです。
表示が煩雑であればその旨もお知らせください。
